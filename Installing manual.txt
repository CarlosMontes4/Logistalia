*              ANGULAR (LOGIS_X)                 *
*                                                *
**************************************************


| Componente            | Versión Requerida            |
| --------------------- | ---------------------------- |
| Node.js               | `v22.14.0`                   |
| npm                   | `11.2.0`                     |
| Angular CLI           | `v19.2.0`                    |

| IDE                   | `Visual Studio Code`         |



Instalación:


✅ PASO 1: Verifica Node, npm y Angular
Abre una terminal (PowerShell, CMD o VSC terminal) y ejecuta:
node -v         # Debe mostrar v22.14.0
npm -v          # Debe mostrar 11.2.0
ng version      # Verifica Angular CLI v19.2.0

Si alguna versión no coincide:

Instala Node.js desde: https://nodejs.org
 
Instala Angular CLI globalmente (si no está) con el siguiente comando -> npm install -g @angular/cli@19

✅ PASO 2: Clona o copia el proyecto
Si el proyecto está en un repositorio:
git clone https://github.com/alemadorran/LOGIS_X.git    ->>>>>>>>>>>>>>>>>>>>< CAMBIAR si lo vas a adjuntar al proyecto

✅ PASO 3: Instala las dependencias
En la terminal dentro de VS Code:

npm install


✅ PASO 5: Levanta el servidor de desarrollo
En la terminal de VS Code, ejecuta: ng serve

✅ PASO 6: Abre el navegador
Angular abrirá el navegador automáticamente, pero si no lo hace, accede manualmente a:
http://localhost:4200


/* Si no se viera bien el proyecto puede ser que no haya descargado bien las dependencias de daisyUI  */
Para instalar la dependencia de DaisyUI / Tailwind 
sigue las indicaciones a partir del paso 2 que se indica en la siguiente DOC: 
https://daisyui.com/docs/install/angular/



**************************************************
*                                                *
*             SPRING BOOT (LOGIS_Y)              *
*                                                *
**************************************************

| Campo                  | Valor Ficticio                            |
| ---------------------- | ----------------------------------------- |
| Nombre del Proyecto    | `logis_y`                                 |
| Descripción            | Aplicación web Spring Boot para logística |
| Versión Spring Boot    | `3.5.0`                                   |
| Java requerido         | `17`                                      |
| Gestor de dependencias | `Maven` (`pom.xml`)                       |
| Base de datos          | `MySQL`                                   |
| ORM                    | `Spring Data JPA`                         |


✅ 1. Requisitos del Entorno
Asegúrate de tener lo siguiente instalado en tu ordenador:
| Herramienta       | Versión mínima recomendada |
| ----------------- | -------------------------- |
| Java JDK          | `17`                       |
| Maven             | `3.8+`                     |
| IDE (recomendado) | `IntelliJ IDEA`            |
| MySQL Benchwork   | `8.0+`                     |


Verificar Java JDK 17
Abre la terminal (CMD o PowerShell) y escribe:
java -version
Si ves algo como:
		java version "17.0.12"  
		Java(TM) SE Runtime Environment ...
Entonces ya tienes Java 17 o superior instalado.

Si no tienes java...
Instalar Java JDK 17 (si no está instalado)
Ve a:
https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html
o usa una alternativa como Adoptium.

Descarga el instalador .msi para Windows (x64).

Instálalo y anota la ruta (ej. C:\Program Files\Java\jdk-17).

✅ PASO 2: Clona o copia el proyecto
Si el proyecto está en un repositorio:
git clone https://github.com/alemadorran/LOGIS_Y.git            ->>>>>>>>>>>>>>>>>>>>< CAMBIAR si lo vas a adjuntar al proyecto

✅ 3. Instalar dependencias
Desde la raíz del proyecto, en terminal:

mvn clean install

✅ 4. Ejecutar la aplicación
Desde intellij ejecutar la aplicacion desde la clase LogisYApplication

✅ 5. Verificar ejecución
Por defecto, Spring Boot usa el puerto 8080. Abre en navegador:
http://localhost:8080
